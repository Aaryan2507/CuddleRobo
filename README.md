<h1>CuddleRobo</h1>

Hey, I am Aaryan, an electronics student trying to learn as much about the world of embedded development as possible.
This repository is a simple introduction and execution of the FluxGarage/RoboEyes library by FluxGarage, which is an incredible library to create eye movements on SSD1306 or SH110X OLED Displays.

FluxGarage's library: https://github.com/FluxGarage/RoboEyes
